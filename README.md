# 15000 西班牙语单词随身背 · 互动学习站

《最好用最好记15000西班牙语单词随身背》(苏珊娜 / 王蕴, 海豚出版社 2016) 完整版互动学习网站。

> 数据来源：原书共 **8 大篇、47 个大类、389 个小节**、**5,937 个词条**、**1,819 条经典实用例句**（含影视出处），加上修复后的西语特殊字符（`ñ / ¿ / ¡`、原书排版断字 `vi-sita → visita`）。

## 功能

### 📖 完整还原原书结构
按 **篇 → 大类 → 小节** 三级层级导航，每个小节含三个原书固定板块：

- **终极分类词**：场景核心词表（中/西/词性）
- **经典实用句**：原汁原味的地道西语句 + 中文翻译 + 影视出处（例《绝望的主妇》《美女上错身》《公主日记》等）
- **词汇大拓展**：相关词/搭配拓展

### 🔊 三档语音
- 西班牙语女声 `es-ES-ElviraNeural`
- 中文女声 `zh-CN-XiaoxiaoNeural`
- 例句、词条、拓展词全部真人发音，**每个词/句独立 mp3 离线播放**

### ▶ 全盘播放（核心功能）
底部固定控制条，三档范围 + 四档顺序：
- 范围：本节 / 本大类 / 全书
- 顺序：西→中（逐条）/ 全部西语→全部中文 / 仅西语 / 仅中文
- 语速：0.7× / 0.85× / 1.0× / 1.15×
- 间隔：无 / 0.4s / 0.9s / 1.8s
- 可循环
- 当前行实时高亮 + 自动滚动到可视区
- **双 Audio 交替 + 预载下一条**，实现无缝衔接

### 🔍 其他
- 全局搜索（西语/中文，跨全 8 篇，搜索时按需加载所有分册）
- 词条点读（点击任意西语词或中文释义单独发音）
- 进度标记（每节"学完"状态，存浏览器 `localStorage`）
- 深色 / 浅色主题
- 移动端响应式（侧栏抽屉 + 紧凑播放条）
- 键盘快捷键：`空格`播放/暂停，`←` `→`上下条，`/` 聚焦搜索

## 部署

可直接部署到 GitHub Pages 或任何静态主机。

## 技术栈

零依赖、零构建：原生 HTML / CSS / JavaScript，**单文件 SPA**。
- 边缘服务：`edge-tts` 7.2.8（Microsoft Azure TTS）
- 字符修复：正则 + 保护词性缩写 / URL + 断字合并
- 性能：分册懒加载（首屏 21KB）+ 音频独立去重缓存

## 制作

源 azw3 → Python `mobi` 解包 → xhtml 结构化（保留篇/Parte/Sección/三板块层级）→ 文本去重 + 字符修复 → `edge-tts` 批量生成 → 数据拆分懒加载 → 浏览器端播放引擎。
