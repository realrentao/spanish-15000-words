# 西班牙语单词随身背 · 互动学习站

**线上地址**：<https://realrentao.github.io/spanish-15000-words/>
**源码仓库**：<https://github.com/realrentao/spanish-15000-words>

> 数据来源：原书共 **9 大篇、48 个大类、390 个小节**、**5,937 个词条**、**1,819 条经典实用例句**（含影视出处），加上修复后的西语特殊字符（`ñ / ¿ / ¡`、原书排版断字 `vi-sita → visita`）。第九篇《时尚热词》为新增专题（时尚/潮流/穿搭/美发词汇，米兰发型师向）。

## 功能

### 📖 完整还原原书结构
按 **篇 → 大类 → 小节** 三级层级导航，每个小节含三个原书固定板块：

- **终极分类词**：场景核心词表（中/西/词性）
- **经典实用句**：原汁原味的地道西语句 + 中文翻译 + 影视出处（例《绝望的主妇》《美女上错身》《公主日记》等）
- **词汇大拓展**：相关词/搭配拓展

### 🔊 三档语音
- 西班牙语女声 `es-ES-ElviraNeural`
- 中文女声 `zh-CN-XiaoxiaoNeural`
- 例句、词条、拓展词全部真人发音，**每个词/句独立 mp3 离线播放**

### 🔤 拼音 + 西语音标（IPA）
- 中文释义标注 **拼音**（pypinyin 生成，如 `xīng qī zhōu`）
- 西语单词/例句标注 **国际音标**（规则化西→IPA，如 `/semˈana/`）
- 顶栏「拼」按钮一键显示/隐藏，零基础也能对照发音

### 🎴 学习模式（闪卡 + 测验 + SRS）
顶栏「学」按钮进入，三种节奏任选：
- **闪卡**：正面西语 + 音标，点击/空格翻面出中文 + 拼音，标记「认识 / 不认识」
- **测验**：给中文释义，四个西语选项选一，即时判分（correct 标绿 / wrong 标红），自动读西语音频
- **SRS 间隔重复**：每个词记录对错与下次复习时间（10 分钟 / 1 小时 / 1 天 / 3 天 / 7 天），「仅到期」可优先巩固薄弱词
- 范围：本节 / 本大类 / 全书；支持乱序
- 进度存 `localStorage`（Key `sv15000_srs`），换设备可导出/导入

### 📦 离线版 + 进度备份
- **离线 ZIP**：整站打包（含全部音频，约 165 MB），解压后本地双击 `index.html` 用任意 HTTP 工具打开即可学习，无需联网
- **进度导出/导入**：在说明弹窗内「导出 / 导入」当前学习进度与复习记录（JSON 文件），纯前端无服务器

### ▶ 全盘播放（核心功能）
底部固定控制条，三档范围 + 四档顺序：
- 范围：本节 / 本大类 / 全书
- 顺序：西→中（逐条）/ 全部西语→全部中文 / 仅西语 / 仅中文
- 语速：0.7× / 0.85× / 1.0× / 1.15×
- 间隔：无 / 0.4s / 0.9s / 1.8s
- 可循环
- 当前行实时高亮 + 自动滚动到可视区
- **双 Audio 交替 + 预载下一条**，实现无缝衔接

### 🔍 其他
- 全局搜索（西语/中文，跨全 8 篇，搜索时按需加载所有分册）
- 词条点读（点击任意西语词或中文释义单独发音）
- 进度标记（每节"学完"状态，存浏览器 `localStorage`）
- 深色 / 浅色主题
- 移动端响应式（侧栏抽屉 + 紧凑播放条）
- 键盘快捷键：`空格`播放/暂停，`←` `→`上下条，`/` 聚焦搜索

## 本地预览

```bash
cd spanish-vocab-site
python -m http.server 8811
# 浏览器打开 http://127.0.0.1:8811/
```

> 注意：必须通过 HTTP 服务打开，直接双击 `index.html`（`file://`）会因浏览器 CORS 限制无法加载 `data/*.js`。

## 部署

GitHub Pages（`main` 分支根目录，自动构建）。

```bash
git remote set-url origin ssh://git@ssh.github.com:443/realrentao/spanish-15000-words.git
git push origin main
```

> 仓库总量 ~165 MB、12,878 个音频文件，单次 `git push` 容易超时。
> 建议分批提交推送（每批 2,000 个文件），脚本见 `.gitignore` 之外的 `_push_batches.py` 思路：
> `git add --pathspec-from-file=<清单>` → `git commit` → `git push`，失败则 `git reset --soft HEAD~1` 后重跑续传。

## 技术栈

零依赖、零构建：原生 HTML / CSS / JavaScript，**单文件 SPA**。
- 边缘服务：`edge-tts` 7.2.8（Microsoft Azure TTS）
- 字符修复：正则 + 保护词性缩写 / URL + 断字合并
- 性能：分册懒加载（首屏 21KB）+ 音频独立去重缓存

## 制作

源 azw3 → Python `mobi` 解包 → xhtml 结构化（保留篇/Parte/Sección/三板块层级）→ 文本去重 + 字符修复 → `edge-tts` 批量生成 → 数据拆分懒加载 → 浏览器端播放引擎。
